## How to use this list
1. Work through each pattern's ★ flagship problem first — read approach in the companion file, then solve it yourself before checking code.
2. Once ★ clicks, do the other 2–4 problems in that pattern **without** looking at the approach — this is what actually builds recall speed for the OA.
3. Re-attempt any pattern where you got stuck after 3–4 days (spaced repetition beats one-time grinding).
4. Infosys OA leans heavily on: Arrays/Strings (§1–4, 22), Sliding Window (§3), Hashing (§9), Stack (§10), basic DP (§18), and Sorting/Searching (§5–6, 8) — prioritize these if time is short.
